# fireworks_supervised_fine_tuning_job (Resource)

A supervised fine-tuning job. Jobs run asynchronously and are immutable;
changes force replacement. Terraform does not wait for the job to finish —
track progress via the `state` attribute on refresh.

~> Running a fine-tuning job incurs training costs on your Fireworks account.

## Example Usage

```terraform
resource "fireworks_dataset" "training" {
  dataset_id    = "training-data"
  external_url  = "gs://my-bucket/train.jsonl"
  format        = "CHAT"
  example_count = 1200
}

resource "fireworks_supervised_fine_tuning_job" "tune" {
  display_name  = "tune llama for support tickets"
  dataset       = fireworks_dataset.training.name
  base_model    = "accounts/fireworks/models/llama-v3p1-8b-instruct"
  epochs        = 2
  learning_rate = 0.0001
  lora_rank     = 8
}

# Deploy the fine-tuned model once the job completes.
data "fireworks_model" "tuned" {
  id = element(split("/", fireworks_supervised_fine_tuning_job.tune.output_model), 3)
}
```

## Schema

### Required

- `dataset` (String) Training dataset, e.g. `accounts/my-account/datasets/my-dataset`. Forces replacement.

### Optional

All optional attributes force replacement.

- `display_name` (String) Human-readable name.
- `base_model` (String) Base model to fine-tune. Exactly one of `base_model` or `warm_start_from` must be set.
- `warm_start_from` (String) Existing fine-tuned model to continue training from.
- `output_model` (String) Name for the resulting model. Generated by the API when omitted.
- `evaluation_dataset` (String) Dataset used for evaluation during training.
- `epochs` (Number) Number of training epochs.
- `learning_rate` (Number) Learning rate.
- `lora_rank` (Number) LoRA rank.
- `batch_size` (Number) Training batch size.
- `max_context_length` (Number) Maximum context length used during training.
- `early_stop` (Boolean) Stop training early when evaluation loss stops improving.

### Read-Only

- `id` (String) Job ID.
- `name` (String) Full resource name.
- `state` (String) Job state (`JOB_STATE_CREATING`, `JOB_STATE_RUNNING`, `JOB_STATE_COMPLETED`, `JOB_STATE_FAILED`, `JOB_STATE_CANCELLED`).
- `create_time` (String) Creation timestamp.
- `completed_time` (String) Completion timestamp, empty while running.

## Import

```shell
terraform import fireworks_supervised_fine_tuning_job.tune <job-id>
```
